# PRISADKA

**Присадка для Biesse NC1000**

Десктопное приложение на Python + Tkinter для создания, редактирования и визуализации программ присадки формата `.anc` для присадочного станка **Biesse NC1000**.

---

## Возможности

- Визуализация панели с отверстиями и пазом
- Редактирование отверстий в пласти и в кромках
- Поддержка массивов отверстий (повторы + смещения)
- Зеркалирование по X / Y
- Загрузка и сохранение файлов `.anc`
- Поддержка арифметических выражений в координатах (`LX/2`, `100+32` и т.д.)
- Паз под задний полик (секция `CONTORNATURA01`)
- Цветовая легенда по диаметрам
- Горячие клавиши (Delete, F3, Ctrl+N / O / S)

---

## Структура проекта

| Файл | Назначение |
|------|------------|
| `test.pyw` | Главный файл приложения (точка входа) |
| `config.py` | Константы, цвета, размеры по умолчанию |
| `hole_manager.py` | Модель отверстий, менеджер и фабрика |
| `file_handler.py` | Чтение / запись `.anc` файлов |
| `geometry.py` | Преобразование координат, вычисление выражений |
| `visualization.py` | Отрисовка панели на Canvas |
| `ui_components.py` | Компоненты интерфейса |
| `dialogs.py` | Диалоги добавления / редактирования |
| `groove.py` | Модель паза |
| `PRISADKA_RULES.md` | **Правила генерации `.anc` для AI-инструментов** |
| `FASAD.anc` | Пример файла программы |

---

## Формат `.anc`

Поддерживается стандартный формат программ Biesse NC1000:

- Секция `[PARAMETRI01]` — размеры детали
- Секция `[CONTORNATURA01]` — паз
- Секция `[TABELLEFORI01]` — отверстия

Подробные правила генерации программ (для AI и автоматизации) описаны в файле:

**[PRISADKA_RULES.md](PRISADKA_RULES.md)**
